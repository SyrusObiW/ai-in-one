AI-in-One Dashboard
報表介紹

AI-in-One Dashboard 是 Microsoft 在 GitHub 上提供的 Power BI 範本，用於彙整 Microsoft Copilot 與 Agent 的採用相關資料本頁說明報表的用途、資料來源、版本差異，並附上報表展示

Overview

報表簡介

AI-in-One Dashboard 將 Microsoft Copilot 與 Agent 的採用資料集中在同一份 Power BI 報表中呈現

📊

報表定位

一份 Power BI 報表，涵蓋 Microsoft Copilot 與 Agent 的採用資料

🗂️

資料來源

資料由 IT 系統管理員從 Purview、Entra 與 M365 系統管理中心匯出，再處理成報表所需的 Rollup 檔案格式

📄

授權方式

範本以 MIT 授權發佈於 GitHub，並附有說明文件與影片指南

Purpose

報表用途

依專案說明，報表提供 Copilot 與 Agent 採用狀況的資訊，供 AI 與業務主管在以下三個面向參考

🧭

AI 導入

了解 Copilot 與 Agent 在組織內的採用情形

🎫

授權

以使用資料作為授權配置的參考依據

🎓

賦能

作為規劃訓練與推廣活動的參考

Data Flow

資料流程

範本讀取的是預先處理過的 Rollup 檔案；建議使用 PAX（Purview Audit eXporter）腳本產生

匯出資料

IT 系統管理員從 Purview、Entra 與 M365 系統管理中心匯出所需資料

執行 PAX

以 PAX v1.11.1 以上版本搭配 -Rollup 參數，產生範本所需的 Rollup 檔案

開啟範本

在 Power BI Desktop 開啟 .pbit 範本，指定檔案位置（本機、SharePoint 或 OneLake）

發佈與排程

發佈至 Power BI Service；使用 SharePoint 版本即可設定自動排程重新整理

Editions

版本說明

兩個版本共用完全相同的頁面、視覺效果與數字，差別只在於資料來源位置，以及能否在 Power BI Service 中排程重新整理

Rollup Edition（3-in-1 自動偵測）Rollup Edition — PBI-SharePoint
資料來源位置本機路徑、SharePoint URL 或 OneLake URL，自動偵測僅限 SharePoint URL
最適合Power BI Desktop 分析、快速本機試用、OneLake / Fabric發佈至 Power BI Service 並自動排程重新整理
Service 排程重新整理❌ 不支援✅ 支援，不需要 Gateway
手動 / 隨選重新整理✅ Desktop（及 Service 隨選）✅
